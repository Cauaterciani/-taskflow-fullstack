# Dia 1 — Git, GitHub e preparação do ambiente

## O que revisei

- Diferença entre Git e GitHub
- Repositório local e remoto
- Commit e push
- Comandos básicos do terminal

## Comandos praticados

- git status
- git add
- git commit
- git push
- git log

## O que aprendi

Git registra o histórico do projeto localmente.

GitHub hospeda o repositório na internet.

Um commit salva uma versão no computador, enquanto o push envia os commits para o GitHub.
